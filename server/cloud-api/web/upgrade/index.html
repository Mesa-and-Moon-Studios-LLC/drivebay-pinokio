Already have a purchase code?

  1. Open Drivebay on your computer and go to Settings → Edition and license. On the phone, open the Mesa panel and tap Edition and license.
  2. Paste the code (it looks like DBAY-XXXX-XXXX-XXXX-XXXX) and press Activate.
  3. Your code works on as many devices as your edition includes. To move a seat, press Deactivate on the old device.

Activation sends the code, a hashed device id and the device name to this site so seats can be counted. It never sends file names or contents. Your files are encrypted before they reach us and we cannot read them.

Enterprise

Enterprise includes a self-hosted server, an offline license file for networks without internet, and a seat count set by your agreement. A one-time license includes a set number of months of updates, and you can renew updates each year.
