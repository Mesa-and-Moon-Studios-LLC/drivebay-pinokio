Drivebay 3.36.4: one-click desktop update

- Windows, Mac, and Linux servers check the latest GitHub release at most once every 12 hours. Settings has Check for updates.
- Windows shows Update available in the tray and on the page. One click downloads the installer and runs it silently, then restarts the server. The account, port, and settings stay. A version below the published minimum still must update.
- Mac and Linux show Update available on the page. Update downloads the matching tarball, replaces the program files, and restarts the service. Config stays.
- If the check cannot reach GitHub, Drivebay keeps running.
- Android app 3.34.5 (versionCode 33405). Play installs show Update available. Sideloaded installs check GitHub for a newer APK. The Windows installer and the server report 3.36.4.
