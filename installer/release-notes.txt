Drivebay 3.22 adds read-only API tokens on this PC.

This release includes Drivebay-Setup-3.22.exe and drivebay-server-win-x64.zip. The command-line install downloads that zip:

irm https://raw.githubusercontent.com/lordstryfe/drivebay-pinokio/main/install.ps1 | iex

On this PC, Settings can create, list, and revoke a token. The secret is shown once, as db_ plus 32 random bytes, and Drivebay stores only a hash. Each token has a name, a read scope (roots, list, stat, search, download with Range, and thumbnails), an optional folder allowlist, an expiry, and a last-used time.

Clients send Authorization: Bearer to GET /api/v1/roots, /api/v1/list, /api/v1/stat, /api/v1/search, /api/v1/download, and /api/v1/thumb. A path stays inside the allowed folders. A symlink that points outside is refused. Calls are rate limited, and the settings page shows an audit log.

Creating, listing, and revoking a token stays on this PC.
