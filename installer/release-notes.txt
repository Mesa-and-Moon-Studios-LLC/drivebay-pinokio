Drivebay 3.36 adds Mac and Linux installers, a required-update check, and Android 3.34.0.

This release includes Drivebay-Setup-3.36.exe, drivebay-server-win-x64.zip, drivebay-server-linux-x64.tar.gz, drivebay-server-linux-arm64.tar.gz, drivebay-server-darwin-arm64.tar.gz, drivebay-server-darwin-x64.tar.gz, and version-manifest.json.

`/api/health` reports version 3.36. The Windows command-line install still downloads the Windows zip:

irm https://raw.githubusercontent.com/Mesa-and-Moon-Studios-LLC/drivebay-pinokio/main/install.ps1 | iex

On macOS or Linux, unpack the matching tarball and run bash unix/install.sh. The Mac build is unsigned. See docs/phone-as-drive.md to mount a phone, and unix/sign-mac.sh before a later signed build.

version-manifest.json on this release is what older desktop installs read. If GitHub cannot be reached, those installs keep running.

The Android app in the repo is 3.34.0 (versionCode 33400). This release does not attach an APK. Google Play updates stay on Aaron's PC.
