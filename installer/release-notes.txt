Drivebay 3.25 adds an OpenClaw skill that uses an API token on this PC.

This release includes Drivebay-Setup-3.25.exe and drivebay-server-win-x64.zip. The command-line install downloads that zip:

irm https://raw.githubusercontent.com/lordstryfe/drivebay-pinokio/main/install.ps1 | iex

The skill folder is skills/drivebay. It needs Node.js, DRIVEBAY_URL, and DRIVEBAY_TOKEN. Commands are roots, ls, stat, find, get, put, mkdir, mv, and rm. The script talks only to DRIVEBAY_URL. It does not print the token. It does not overwrite a file, and it does not download a file larger than DRIVEBAY_GET_CONFIRM_BYTES (default 20 MB), unless you pass --yes.

A write outside the open window prints "Waiting for approval on Drivebay" and polls GET /api/v1/approvals/<id> until this PC approves, denies, or the request expires.

Publish the skill from the repository root after clawhub login:

clawhub skill publish ./skills/drivebay --slug drivebay --name "Drivebay" --version 1.0.0

Do not include the token in that publish.
