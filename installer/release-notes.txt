Drivebay 3.32 publishes the Windows installer and server at version 3.32.

This release includes Drivebay-Setup-3.32.exe and drivebay-server-win-x64.zip. The command-line install downloads that zip:

irm https://raw.githubusercontent.com/Mesa-and-Moon-Studios-LLC/drivebay-pinokio/main/install.ps1 | iex

`/api/health` reports version 3.32. A forgotten password can be reset on this PC only: the tray menu's Reset password, or `drivebay reset-password`. The login page explains that. There is no remote reset. The saved account hash is updated and existing sessions are signed out. Settings, drives, and API tokens stay.
