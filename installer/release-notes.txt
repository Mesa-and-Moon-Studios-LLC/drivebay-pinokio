Drivebay 3.27 adds a Donate button on the settings page.

This release includes Drivebay-Setup-3.27.exe and drivebay-server-win-x64.zip. The command-line install downloads that zip:

irm https://raw.githubusercontent.com/lordstryfe/drivebay-pinokio/main/install.ps1 | iex

The button opens a menu of GitHub Sponsors, PayPal, and Ko-fi. Each address is a constant in app/src/lib/donate.mjs: DONATE_GITHUB_SPONSORS_URL, DONATE_PAYPAL_URL, and DONATE_KOFI_URL. A blank constant hides that choice. With every constant blank, the button stays off the page. The constants are blank in this release.

.github/FUNDING.yml holds the same links as comments. github: lordstryfe stays commented until GitHub Sponsors is approved.
