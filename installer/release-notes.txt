Drivebay 3.26 moves the suggested port to 8765 so Pinokio's Caddy does not take it.

This release includes Drivebay-Setup-3.26.exe and drivebay-server-win-x64.zip. The command-line install downloads that zip:

irm https://raw.githubusercontent.com/lordstryfe/drivebay-pinokio/main/install.ps1 | iex

Pinokio's Caddy (z:\pinokio\bin\miniforge\Library\bin\caddy.exe) claims ports from 42000 to 42999 while Pinokio is running, even when Drivebay is not installed in Pinokio. The suggested port is 8765. If that port is taken, setup picks the next free port outside that range.

An update keeps a saved port outside 42000-42999. A saved port in that range moves automatically. Setup prints the new address and updates the firewall rule and the shortcut.

If a port is already in use, setup names the program. When the program is Pinokio's Caddy, the message says so and asks for a different port outside that range.
