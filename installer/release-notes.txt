Drivebay 3.23 adds a timed write window for API tokens.

This release includes Drivebay-Setup-3.23.exe and drivebay-server-win-x64.zip. The command-line install downloads that zip:

irm https://raw.githubusercontent.com/lordstryfe/drivebay-pinokio/main/install.ps1 | iex

On this PC, or from a signed-in Tailscale device, choose Allow write for 15 minutes, 1 hour, or 4 hours. During that window a token can upload, create a folder, rename, and delete. When the window ends, the token is read-only again and a write is not performed.

Writes still follow the server lock on this PC. A symlink is not followed into a write, and deleting a symlink removes the link.

Read-only tokens from 3.22 stay the same: the secret is shown once, only a hash is stored, and reads use Authorization: Bearer.
