Drivebay 3.36.7: phone mount on Linux and Mac

- Settings → Mount phone as drive accepts the 6-digit code or the token, saves it in phone-tokens.json, and tells the phone this PC's name.
- An optional drive name is shown in File Explorer. A blank name uses the name the phone sends back.
- Linux and macOS use gio or mount_webdav on a desktop session, and rclone when that session or tool is missing. Nothing asks for the code again. Unmount follows the same method.
- A small support banner can be hidden, and Settings can show it again.
- The Windows installer and the server report 3.36.7. Android stays 3.34.5 (versionCode 33405).
