Drivebay 3.34 fixes the file browser jumping back to the start folder.

This release includes Drivebay-Setup-3.34.exe and drivebay-server-win-x64.zip. The command-line install downloads that zip:

irm https://raw.githubusercontent.com/Mesa-and-Moon-Studios-LLC/drivebay-pinokio/main/install.ps1 | iex

`/api/health` reports version 3.34. Opening a folder or a file now stays put. Before, the browser re-ran its start-folder load on every render, so it snapped back to the start folder and kept sending listing requests to the server.

The Android app in the repo is still 3.33.0. This release does not attach an APK.
